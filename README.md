# LexiVoice — Dyslexia Reading Companion

LexiVoice is a web-based reading assistant designed to help people with dyslexia read more easily, comfortably, and confidently. It translates normal text into customized visual formats and adds speech tools to make reading stress-free.

---

## 🌟 Key Features (In Easy Language)

- **📄 Upload and Paste Text**: Easily drop in any PDF or TXT file, or type/paste text directly to start reading immediately.
- **🔗 Read from the Web**: Paste any website link to extract its text and read it without distracting ads or layouts.
- **✨ Bionic Reading**: Bolds the beginning parts of words (like **thi**s or **tha**t) to guide your eyes and speed up your reading.
- **🔊 Read Aloud (Voice)**: Plays the text out loud with adjustable voice speeds, pitch, and volume. It highlights words as it reads them.
- **🔍 Word Breakdown (Tooltip)**: Click or double-click any word to hear how it sounds, see it broken into syllables, or read its definition.
- **🎨 Custom Backgrounds**: Choose from soft, eye-friendly backgrounds (cream, mint, lavender, peach, sky blue, or soft yellow) or set your own text and background colors to prevent eye strain.
- **📏 Focus Ruler & Shading**: Use a highlight bar to stay on your current line while darkening the rest of the text.
- **📦 Chunk (One-Paragraph) Mode**: View only one paragraph at a time, moving forward or backward using simple arrow buttons, so you don't feel overwhelmed.
- **💡 Word Simplifier**: Automatically changes long, complicated words to easier, everyday words with the press of a button.
- **🧘 Eye Rest Breaks**: Reminds you to take breaks with guided breathing exercises to keep your brain fresh.
- **🎮 Learning Studio**: A fun practice center with:
  - **Phonics Practicing**: Hear words and sound them out syllable by syllable.
  - **Flashcards**: Practice common sight words.
  - **Fun Games**: Play word puzzles to test your reading.
- **👶 Child & Teacher Presets**: One-click setups to make the page kid-friendly or allow parents and teachers to guide settings.
- **⌨️ Keyboard Shortcuts**: Control playing, pausing, rulers, font size, and more entirely from your keyboard (like hitting `SPACE` to pause or `R` for the ruler).

## 🚀 How to Run It

Since this is a simple web application, you do not need to install complicated software.

### Option 1: Quick Start (No Setup Required)
1. Locate the `index.html` file in the project folder.
2. Double-click `index.html` to open it in your favorite web browser (Chrome, Edge, Firefox, or Safari).
*Note: The "Read from the Web" link import option might not work with this method because of browser security rules (CORS).*

### Option 2: Full Server Launch (Includes Link Importing)
If you want to use the webpage importing feature, run it with a server:
1. Open your terminal or command prompt in the `LexiVoice` folder.
2. If you have Node.js installed, run:
   ```bash
   npx vercel dev
   ```
3. Open your browser and navigate to `http://localhost:3000`.
