Keyboard Shortcuts

Control LexiVoice quickly without touching your mouse using these shortcuts:

SPACE Play / Pause reading
R Toggle Reading Ruler guide
F Toggle Line focus dimming helper
B Toggle Bionic reading bold anchors
Y Toggle Alternating Syllables color
V Toggle Letter Reversal Helper (b/d/p/q)
C Toggle Chunk (one-paragraph) mode
S Open settings customization panel
← → Prev / Next paragraph (in Chunk mode)
↑ ↓ Move ruler up / down (when manual and locked)
+ - Increase / Decrease reading font size
? Open this shortcuts help guide
ESC Close any open panel or popup dialog
